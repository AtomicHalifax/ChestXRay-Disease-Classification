# Project Poster

This directory contains the project poster for the **Chest X-Ray Disease Classification** project.

The poster summarizes the complete project in a concise visual format, highlighting:

* Project objective
* Dataset
* Model architecture
* Training methodology
* Evaluation metrics
* Experimental results
* Grad-CAM visualizations
* Key takeaways

It is designed for academic showcases, technical presentations, portfolio demonstrations, and conference-style project summaries.
