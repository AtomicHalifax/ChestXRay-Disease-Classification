# Project Presentation

This directory contains the presentation for the **Chest X-Ray Disease Classification** project.

The presentation provides a high-level overview of the project, including:

* Project motivation
* Clinical problem
* Dataset overview
* Model architecture
* Training configuration
* Performance evaluation
* ROC and Precision–Recall analysis
* Grad-CAM explainability
* Error analysis
* Key findings and conclusions

The presentation is intended for quick technical reviews, project demonstrations, interviews, and portfolio presentations.
