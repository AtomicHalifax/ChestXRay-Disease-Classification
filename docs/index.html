The best epoch was picked on that same validation set, so 0.879 is optimistic (it ranged 0.854–0.879 across epochs 6–10). On outside images from other hospitals the model does noticeably worse — which is why the service checks every input and watches for drift.

How it works

A model is the easy part. Here's the rest.

Train & track

PyTorch training with patient-level splits, logged to MLflow. Weights versioned on Hugging Face and pinned by SHA-256.

Gate before release

CI runs tests and a quality gate: a new model can't ship if AUROC drops against the baseline.

Ship as a container

FastAPI in Docker, published to GHCR on every release tag and running on AWS EC2 behind HTTPS.

Guard the input

Colour photos, tiny images and odd shapes are flagged before anyone trusts the answer.

Explain

Grad-CAM shows where the evidence came from — and when the model is looking at the wrong thing.

Monitor drift

Prometheus + Grafana track latency, errors and a PSI drift score comparing live predictions with validation.
