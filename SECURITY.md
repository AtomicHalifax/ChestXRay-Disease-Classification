# Security Policy

## Supported Versions

This repository is maintained primarily for educational, research, and portfolio purposes.

Security updates may be provided periodically, but long-term support is not guaranteed.

---

## Reporting a Vulnerability

If you discover a security vulnerability related to this repository, please **do not open a public GitHub issue**.

Instead, contact the repository maintainer privately with:

* A description of the issue
* Steps to reproduce the problem
* Potential impact
* Suggested remediation (if available)

The issue will be reviewed and addressed as appropriate.

---

## Scope

This project does **not** provide any online services, APIs, or production deployments.

The repository contains research code intended for local experimentation and learning.

Users are responsible for securing their own environments when running the code.

---

## Responsible Disclosure

Please allow reasonable time for any reported issue to be reviewed before publicly disclosing the vulnerability.

Responsible disclosure helps protect users and maintains the integrity of the project.
